# Telegram Backup Tool | 电报数据备份工具

A simple and secure synchronization tool designed for backing up and archiving Telegram chat messages and media files to protect your data loss.

一款安全、简便的 Telegram 数据同步与归档工具，旨在帮助用户备份重要的聊天记录与媒体文件，防止数据丢失。
